# EXOCRIRES
-- A homemade CRIRES+ observation simulator for direct-imaged planets-- 

Welcome to EXOCRIRES V1.0! This is a 2-D synthetic observation pipeline/mock observation simulator to analyze the feasibility of high-contrast spectroscopy for direct-imaged planetary systems.
